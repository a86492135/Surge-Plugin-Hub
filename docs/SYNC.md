# 每日检查 · PR 审核更新

## 工作方式

GitHub Actions 每天北京时间 10:17 检查上游，也提供手动执行入口。定时任务可能排队；长期不活跃的公开仓库，定时任务可能被 GitHub 停用，可在 Actions 重新启用。

1. 高德优先使用指定目录中的 Surge 原生模块。
2. 微博先检查同一目录中的普通微博模块，再读取用户提供的可莉 Loon 直链并尝试转译；当前不可读时使用已审阅的备用源。
3. 高德、微博解析外部来源并固定脚本提交；飞常准读取本仓库的本地规则列表。统一应用元数据与 overrides 层。
4. 执行规则静态检查及本地脚本模拟测试。
5. 无变化时不创建 PR；有变化时更新 belief/upstream-sync 分支并创建或更新同一个开放 PR。
6. 维护者检查差异、实测后合并。main 的 Raw 链接才会更新，手机 Surge 还需刷新远程模块。README 模块目录同时更新。

不自动合并。同步 PR 和发布是两个步骤。PR 由 GitHub 的临时令牌创建，不需要把个人 Token 写入仓库。

## 可配置内容

- config/modules.json：名称、作者、分类、简短描述、来源与来源优先级。
- overrides/amap.sgmodule：高德自定义层，独立于上游。
- rules/variflight-pro.list：用户提供的本地规则；手动维护，不从网络替换。
- upstream.lock.json：实际使用的来源修订、固定脚本及摘要。
- upstream-review.json：优先源的可读性和待审核原因。

## Loon 转译边界

已实现常见域名规则、拒绝/重定向重写、普通 HTTP 脚本参数和 MITM 域名的转译。现成的 Surge Body Rewrite / Map Local 格式可直接保留。

外部 JQLang、webview 引擎、参数化插件、未知节、Loon 特有匹配选项和未审阅脚本依赖不会被猜测转换或静默删除；记录为待审核，继续使用已审阅备用源。模块支持通用格式转换不等于所有 Loon 插件均已完成兼容性验证。

可莉 Loon 微博源为：https://kelee.one/Tool/Loon/Lpx/Weibo_remove_ads.lpx 。当前本地读取返回 HTTP 403；没有绕过访问限制。

## 仓库设置

自动开 PR 需要仓库允许 GitHub Actions 创建 Pull Request。若设置被禁用，工作流会保留失败信息；在 Settings → Actions → General 中允许该能力后重新运行。不应为解决这一项而开启其他无关权限。

## 验证边界

工作流验证的是构建和转换，不代表手机效果通过。配置、manifest 和首页目录记录相同的验证级别与范围。高德目前为部分实机验证：开屏、扫街榜2026入口和双11横幅已确认；底栏隐藏未实现。微博与飞常准仍待实机验证。

手动来源与外部来源都进入构建和检查，但只有外部来源会拉取远程更新。同步程序先解析全部来源，验证通过后再写入模块；飞常准规则不会被上游文件覆盖。
